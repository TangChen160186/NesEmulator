# 04 · 2A03 APU：五个声道与音频输出

> APU（Audio Processing Unit）集成在 2A03 CPU 芯片内部。它没有“音频文件”概念，
> CPU 只写频率、音量、长度等寄存器，APU 用硬件定时器现场合成波形。

## 1. 声道总览

```text
Pulse 1 ─┐
Pulse 2 ─┼─> 混音器 ─> DAC ─> 电视/音频输出
Triangle ─┤
Noise ────┤
DMC ──────┘
```

| 声道 | 波形 | 主要用途 | 音量控制 |
|---|---|---|---|
| Pulse 1/2 | 方波，4 种占空比 | 旋律、和声、音效 | 包络/固定音量 + 扫频 |
| Triangle | 32 级三角波 | 低音、旋律 | 无音量，仅开/关 |
| Noise | 15 位 LFSR 伪随机 | 鼓、爆炸、风声 | 包络/固定音量 |
| DMC | 1 位 delta PCM | 采样人声/鼓 | 7 位 DAC 电平 |

## 2. 寄存器地图

APU 占用 CPU 的 `$4000-$4017`：

| 地址 | 声道 | 作用 |
|---|---|---|
| `$4000-$4003` | Pulse 1 | 占空比/包络、扫频、定时器低、长度/定时器高 |
| `$4004-$4007` | Pulse 2 | 同上 |
| `$4008-$400B` | Triangle | 线性计数器、定时器低、长度/定时器高 |
| `$400C-$400F` | Noise | 包络、周期/模式、长度 |
| `$4010-$4013` | DMC | IRQ/循环/采样率、DAC、地址、长度 |
| `$4015` | 全局 | 读状态/IRQ；写声道使能 |
| `$4017` | 全局 | 帧序列器模式与 IRQ 抑制 |

### 2.1 $4015 状态

读：

```text
bit 0 Pulse 1 长度计数器非零
bit 1 Pulse 2
bit 2 Triangle
bit 3 Noise
bit 4 DMC 还有字节要播放
bit 6 帧 IRQ
bit 7 DMC IRQ
```

读 `$4015` 会清除帧 IRQ 和 DMC IRQ。

写：

```text
bit 0-3 分别启用 Pulse1/Pulse2/Triangle/Noise
bit 4   启用 DMC
```

关闭某个声道会清空它的长度计数器。

## 3. 包络、长度与扫频

这三个部件是“音符生命周期”的核心。

### 3.1 包络 Envelope

由 `$4000/$4004/$400C` 控制：

```text
bit 5  loop
bit 4  constant volume
bit 3-0 周期/固定音量
```

工作方式：

- constant=1：输出固定音量 `bit3-0`；
- constant=0：从 15 开始，每 quarter frame 递减；
- 减到 0 后，如果 loop=1 则回到 15，否则保持 0；
- 写长度寄存器（`$4003/$4007/$400F`）会触发 `Start()`，下次时钟重置到 15。

代码：[`ApuComponents.cs`](../src/NesEmulator.Core/Apu/ApuComponents.cs)

### 3.2 长度计数器 Length Counter

- 32 个硬件长度值（10, 254, 20, 2, ...）；
- 由长度寄存器的 bit7-3 选择；
- 每 half frame 递减一次；
- 减到 0 时声道静音；
- 写 `$4015` 对应位为 0 时清零。

长度表在 `LengthCounter.LengthTable`。

### 3.3 扫频 Sweep（仅 Pulse）

`$4001/$4005`：

```text
bit 7    使能
bit 6-4  周期（每 half frame 递减）
bit 3    取负
bit 2-0  移位量
```

目标周期：

```text
change = timer >> shift
target = negate ? timer - change (-1 for Pulse 1) : timer + change
```

Pulse 1 取负使用反码（额外 -1），Pulse 2 使用补码。这是两者的真实硬件差异。
当目标超出 11 位范围或当前周期 < 8 时，输出静音。

## 4. Pulse 声道

占空比序列（8 步）：

| 占空比 | 序列 |
|---|---|
| 12.5% | 0 1 0 0 0 0 0 0 |
| 25% | 0 1 1 0 0 0 0 0 |
| 50% | 0 1 1 1 1 0 0 0 |
| 75% | 1 0 0 1 1 1 1 0 |

定时器：

```text
每 (timer + 1) * 2 个 CPU 周期，占空比相位 +1
```

`timer` 是 11 位（`$4002` 低 8 位 + `$4003` 低 3 位）。
写 `$4003` 会重置相位，使音头清晰。

输出：

```text
if length > 0 and timer >= 8 and not sweep_muted:
    volume if duty[phase] else 0
```

## 5. Triangle 声道

- 32 步波形：`15,14,...,0,0,1,...,15`；
- 定时器每 `timer+1` 个 CPU 周期前进一步；
- 没有音量控制；
- 线性计数器（linear counter）与长度计数器共同决定是否发声；
- 周期小于 2 时输出静音（超声波）。

`$4008`：

```text
bit 7    控制标志（同时作为长度 halt）
bit 6-0  线性计数器重载值
```

每 quarter frame：

```text
if reload: linear = reloadValue
else if linear > 0: linear--
if control == 0: reload = false
```

## 6. Noise 声道

15 位线性反馈移位寄存器：

```text
feedback = bit0 xor (mode ? bit6 : bit1)
shiftRegister = (shiftRegister >> 1) | (feedback << 14)
```

- 初始值通常为 1；
- bit0 为 0 时输出包络音量；
- `$400E` bit7 选择短模式（bit6 反馈）；
- `$400E` bit3-0 选择 NTSC 周期表。

周期表（CPU 周期）：

```text
4, 8, 16, 32, 64, 96, 128, 160,
202, 254, 380, 508, 762, 1016, 2034, 4068
```

## 7. DMC 声道

DMC 是 NES 上唯一能播放 PCM 采样的通道：

- 从 CPU 地址空间 `$C000-$FFFF` 读取 1 位 delta 编码样本；
- 每个 bit：1 让 DAC 电平 +2，0 让 -2，范围 0-127；
- 播放会占用 CPU 总线（真实硬件会暂停 CPU 若干周期）；
- 有独立的 IRQ 和 loop 标志。

寄存器：

| 地址 | 作用 |
|---|---|
| `$4010` | bit7 IRQ 使能，bit6 循环，bit3-0 采样率 |
| `$4011` | 7 位 DAC 直接加载 |
| `$4012` | 采样地址 = `$C000 + value*64` |
| `$4013` | 采样长度 = `value*16+1` 字节 |

采样率表（CPU 周期）：

```text
428, 380, 340, 320, 286, 254, 226, 214,
190, 160, 142, 128, 106, 84, 72, 54
```

本实现为了让 APU 能读内存，把 `Func<ushort, byte>` 从 `NesBus.Read` 传入
[`DmcChannel.cs`](../src/NesEmulator.Core/Apu/DmcChannel.cs)。

**未实现**：DMC 抢占总线导致的 CPU 停顿。它会影响极端时序和部分测试 ROM，
对普通音乐播放影响较小。

## 8. 帧序列器

APU 用一个约 240 Hz 的帧序列器统一推进包络、长度、扫频和线性计数器。
`$4017` 选择模式：

### 4 步模式（bit7=0，默认）

| CPU 周期 | 动作 |
|---|---|
| 7457 | quarter |
| 14913 | quarter + half |
| 22371 | quarter |
| 29829 | quarter + half，置帧 IRQ（若未抑制） |
| 29830 | 计数器归零 |

### 5 步模式（bit7=1）

| CPU 周期 | 动作 |
|---|---|
| 7457 | quarter |
| 14913 | quarter + half |
| 22371 | quarter |
| 29829 | 无 |
| 37281 | quarter + half，计数器归零，不产生 IRQ |

`$4017` bit6=1 抑制帧 IRQ。读取 `$4015` 会清除已挂起的帧 IRQ。

本实现把“写入 5 步模式立即时钟一次 quarter/half”作为近似；真实硬件有 3-4 个
CPU 周期的延迟。

## 9. 混音

NES 的 DAC 是非线性的。精确模型需要查表，本项目采用 NESdev 常用的线性近似：

```text
pulse = 0.00752 * (Pulse1 + Pulse2)
tnd   = 0.00851 * Triangle
      + 0.00494 * Noise
      + 0.00335 * DMC
sample = clamp(pulse + tnd, 0, 1.5)
```

然后做一阶高通去直流：

```text
y[n] = x[n] - x[n-1] + 0.995 * y[n-1]
```

最后乘 0.8、裁剪到 [-1, 1]，转成 16 位 PCM。

## 10. 采样与宿主音频

APU 的时钟是 1.789773 MHz，输出采样率是 44100 Hz。每个 CPU 周期：

```text
sampleAccumulator += 44100 / 1789773
if sampleAccumulator >= 1: 产生一个样本
```

样本写入 [`AudioBuffer.cs`](../src/NesEmulator.Core/Apu/AudioBuffer.cs) 的环形缓冲。
桌面端 [`WaveOutAudio.cs`](../src/NesEmulator.Desktop/WaveOutAudio.cs) 用 Windows
`waveOut` API 从环形缓冲取数据，排 4 个 1024 样本的缓冲，约 93 ms 延迟。

缓冲区满时丢弃最旧样本，避免模拟线程被音频设备拖死；欠载时补 0。

## 12. 常见陷阱

- 把脉冲定时器当成 `timer` 而不是 `(timer+1)*2`；
- 忘记 `$4003` 写长度/定时器高时启动包络；
- 长度计数器被 halt 后还在递减；
- Pulse 1/2 扫频取负的 1 差异；
- 三角波没有音量却错误地乘包络；
- 噪声 LFSR 反馈位/初始值错误；
- 帧序列器 4/5 步边界差 1；
- `$4015` 读不清 IRQ；
- 混音后直流偏移导致爆音；
- 音频线程与模拟线程共享缓冲没有同步。
