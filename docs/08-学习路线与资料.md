# 08 · 学习路线与外部资料

> 这一篇给出一条可执行的学习路径，以及经过筛选的英文/日文资料入口。
> NES 的资料绝大多数是英文，建议边读边做实验，不要先“看完再做”。

## 0. 预备知识

不需要先成为硬件专家，但以下内容会显著降低门槛：

- 二进制/十六进制、按位与或异或、移位；
- 有符号/无符号整数、溢出；
- 指针/数组/内存地址；
- 基本 C# 或任何 C 系语言；
- 知道“时钟周期”和“中断”大概是什么。

如果这些还不熟，先补 2-3 天即可，不必系统学完整门计算机组成原理。

## 1. 四阶段路线

### 阶段 A：让 6502 跑起来（约 1-2 周）

目标：能解释并实现 CPU 的取指、寻址、标志位、栈和中断。

顺序：

1. 读 [6502 指令集](https://www.masswerk.at/6502/6502_instruction_set.html) 的寄存器/标志；
2. 读 [NESdev CPU](https://www.nesdev.org/wiki/CPU)；
3. 读本项目的 [`Cpu6502.cs`](../src/NesEmulator.Core/Cpu/Cpu6502.cs) 和
   [`OpcodeTable.cs`](../src/NesEmulator.Core/Cpu/OpcodeTable.cs)；
4. 用 nestest 对拍，修到 8,991 条全过；
5. 做练习：手写一个只有 LDA/STA/JMP/BNE 的解释器。

验收：能画出 `JSR`/`RTS` 的栈变化，解释 `LDA $12FF,X` 为什么可能 5 周期。

### 阶段 B：PPU 与画面（约 2-3 周）

目标：从“黑屏”到“能显示背景 + 精灵 + 滚动”。

顺序：

1. 读 [NESdev PPU](https://www.nesdev.org/wiki/PPU) 的 pattern/nametable/OAM；
2. 读本项目的 [`Ppu2C02.cs`](../src/NesEmulator.Core/Ppu/Ppu2C02.cs) 寄存器部分；
3. 实现 `$2006/$2007`，把一块 tile 数据写进 VRAM，显示纯色/棋盘；
4. 实现背景取指和调色板，显示一个静态画面；
5. 实现 OAM + 精灵；
6. 实现 vblank/NMI；
7. 实现 loopy 滚动；
8. 用自制 ROM 和 `sprite_hit_tests` 验证。

验收：能解释 `v/t/x/w` 四个状态，能写出“每帧改滚动”的 NMI 代码。

### 阶段 C：APU、卡带与整机（约 2 周）

目标：有声音、能换 bank、能跑多个 ROM。

顺序：

1. APU 先做 Pulse 1，再 Triangle/Noise，最后 DMC；
2. 读 [NESdev APU](https://www.nesdev.org/wiki/APU) 和帧序列器；
3. 实现 iNES 头和 NROM；
4. 实现 UxROM/CNROM/MMC1；
5. 实现 MMC3 的 bank + 扫描线 IRQ；
6. 把音频输出接到桌面端。

验收：能解释“为什么换 CHR bank 不需要 CPU 复制数据”，能写出 MMC1 的 5 次写序列。

### 阶段 D：做一个小游戏（约 2-4 周）

目标：不再只是“运行 ROM”，而是自己写一个 NES 程序。

顺序：

1. 读 [`09-NES游戏开发流程.md`](09-NES游戏开发流程.md)；
2. 用 ca65/asm6f 写一个最小 ROM；
3. 用 YY-CHR 画 8×8 tile；
4. 用 FamiStudio 写一段音乐；
5. 实现标题、移动、碰撞、卷轴；
6. 在 Mesen 调试器中单步/看 VRAM/OAM；
7. 如果要上真机，了解 mapper 板/烧录器。

验收：能独立完成“标题 → 游戏 → 结束”的循环。

## 2. 配套练习（按难度）

### 练习 1：CPU 单步追踪

给 `Cpu6502.Step()` 加一个可选 `TextWriter`，输出 PC、操作码、寄存器、周期。
要求不破坏 nestest。

### 练习 2：反汇编器

用 `OpcodeTable` 写 `Disassembler.Disassemble(pc, read)`，支持所有寻址方式。
输出示例：

```text
C000  4C F5 C5  JMP $C5F5
C5F5  A2 00     LDX #$00
```

### 练习 3：调色板调试器

在桌面端加一个窗口，显示 32 字节调色板 RAM 和 64 色主调色板。
点击某个色块可以高亮画面中使用该颜色的像素。

### 练习 4：滚动分割

修改演示 ROM，在 NMI 中把屏幕分成上下两部分，使用不同滚动值。
这需要理解 vblank 时间预算和 `$2005/$2006` 的写入顺序。

### 练习 5：MMC3 分屏

用 MMC3 IRQ 在屏幕中间触发中断，在 IRQ 处理程序中修改 `$2005`。
这是《超级马里奥兄弟 3》状态栏的经典技术。

### 练习 6：存档状态

按 [`06-源码导读与扩展.md`](06-源码导读与扩展.md) 的清单实现二进制存档，
并用同一个 ROM 验证读档后画面一致。

### 练习 7：PAL

加入 PAL 时序（312 行、50 Hz、不同 APU 表），比较同一游戏的 PAL/NTSC 速度。

## 4. 如何高效阅读英文资料

1. 先用本项目的文档建立中文框架；
2. 遇到寄存器/时序细节，直接查 NESdev 对应页面；
3. 不要逐字读，先看表格和时序图；
4. 每读一个概念，就在代码里找对应实现或写一个小测试；
5. 用截图/日志验证，而不是“感觉应该对”。

## 5. 法律与伦理

- 不要下载/分发商业 ROM；
- 测试 ROM 也有各自许可，遵守上游仓库说明；
- 自制 ROM、自己画的图形、自己写的音乐可以自由分发；
- 模拟器本身在许多司法辖区是合法的，但 ROM 的版权状态不同，请自行判断；
- 不要在项目中加入任天堂的 BIOS、字体、图形或商标资源。
